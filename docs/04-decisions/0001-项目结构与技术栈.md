# 0001 项目结构与技术栈

- 状态：已采纳
- 日期：2026-10-20

## 背景

个人练手项目，目标是让前端开发者逐步掌握后端能力，同时与工作中接触的技术栈保持一致。

## 决策

1. **单仓库（monorepo）**：`web/`、`server/`、`docs/` 放在同一个 git 仓库。
   一个人开发时，前后端改动往往是同一个功能，放一起可以一次提交、一起回溯。
2. **前端**：React 19 + TypeScript + Vite（沿用已有经验）。
3. **后端**：Spring Boot 4.1 + Java 21 + Maven。
   - 与工作中的后端同属 Spring Boot 体系，学到的东西可直接迁移；
   - 选 4.x 而非 3.x：Spring 官方脚手架已不再提供 3.x，新项目应使用当前稳定版。
     与 3.x 的日常写法（Controller、校验、配置）基本一致，差异点遇到时再记录。
   - 使用 Maven Wrapper（`mvnw`），本机无需安装 Maven。
4. **开发期联调**：后端端口 8090（避开工作项目常用的 8080），Vite 代理 `/api` → `localhost:8090`，前端不处理跨域。

## 后果

- 后续引入数据库、鉴权、大模型调用时，各自另开 ADR 记录选型。
